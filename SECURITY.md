# Security policy

## Reporting

Do not disclose vulnerabilities in a public issue. The source repository is public and
GitHub private vulnerability reporting is active through its Security tab. Source
visibility is independent of JSR package and OCI image publication: both distributable
artifacts remain unpublished.

Include the affected version or commit, deployment boundary, and safe reproduction
steps. Do not attach real bearer tokens, persisted `/data` records, or customer data.

## Supported releases

No public package or OCI image release is currently supported. The prepared `0.1.0`
source state is not a security support commitment, even though the source repository is
public.
